# Axis Skills — IQ Tool Wrappers

This directory will hold custom OpenJarvis skills that wrap each IQ product
as a callable tool. Skills follow the [agentskills.io](https://agentskills.io)
open standard.

## Planned Skills (Phase 4)

| Skill | Product | Actions |
|-------|---------|---------|
| `pressureiq.py` | PressureIQ | Trigger assessment, read result, lookup historical pressure mode trends |
| `signaliq.py` | SignalIQ | Query revenue signal, generate intelligence brief, flag opportunity |
| `outreachiq.py` | OutreachIQ | Send sequence, check pipeline, log response |
| `compatibleiq.py` | CompatibleIQ | Lookup profile, run compatibility check, surface shadow profile insight |
| `courtiq.py` | CourtIQ | Log Caleb drill, pull stat history, queue training video |
| `christianiq.py` | ChristianIQ | Pull archetype, surface relevant scripture pattern |

## Specialty Skills (Phase 6)

| Skill | Function |
|-------|----------|
| `devotion_generator.py` | Daily devotion in Chris's format with etymology, cross-references, story, closing |
| `chief_of_staff.py` | Daily focus brief — urgent items, daily drivers, recommended reading |
| `school_outreach.py` | Pull call sheet, generate opener, log result |
